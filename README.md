# DYSTINCT-recording-tool

This is a streamlit-based recording tool for the collection of sentence recordings and spontaneous discourse.

CURRENTLY IN PRODUCTION

## Installation

### Quickstart

Using pip, install the dependencies:

```
pip install -r requirements.txt
```

To run the program, use:

```
streamlit run app.py
```

This should open a tab in your browser and start the recording program.
